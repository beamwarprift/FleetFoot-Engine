# Contributing

The code is public so that anyone can read and verify it. It is written and maintained by one developer, and this repository does not take pull requests.

You can still help a lot:

- Report a bug in [Issues](https://github.com/beamwarprift/FleetFoot-Engine/issues), with the steps that show it.
- Propose an idea in [Discussions](https://github.com/beamwarprift/FleetFoot-Engine/discussions).
- Report a security problem privately, as [SECURITY.md](SECURITY.md) explains.

FleetFoot Engine controls the playback of video and audio and nothing else. Ideas outside that, such as filters, downloads, ad blocking or anything that would send data, stay out by design.

The [license](LICENSE) does not allow changing or redistributing the code.
